核心问题RMSNorm、LayerNorm 里“除以标准差”的标准差到底是什么？4.3 节那张 QKᵀ 打分矩阵，和统计里的协方差矩阵是不是一回事？
本节主张方差是“一组数离均值多远”的尺子，标准差开平方把单位换回来；协方差回答“两个变量怎么一起变”，排成矩阵就是 XᵀX。而注意力的 QKᵀ 与协方差矩阵只是同属“两两点积排成方阵”的二阶矩家族——它是 Gram 矩阵（相似度矩阵）的学习版，不是协方差。
一句话结论归一化用的是方差（除波动），注意力打分用的是学出来的相似度（QKᵀ）——一个家族，两码事。

　　4.3 节图 6 那张 10×10 的注意力权重矩阵，长相很像统计学里的协方差矩阵：都是“两两配对算一个关系值，排成一个方阵”。这个直觉抓到了真东西，但两个矩阵并不是一回事。本节先把地基打好——方差（一组数自己散得多开）与协方差（两组数怎么一起变），再把三个“长得像”的矩阵摆在一起对比，讲清它们各自回答什么问题。

  1. 方差与标准差：一组数离均值有多远（A.14.1）：为什么要平方、为什么要开根号，归一化除的就是它；
  2. 协方差与协方差矩阵：两个变量怎么“一起变”（A.14.2）：正相关、负相关、无关三种形态，矩阵形式 XᵀX；
  3. 三个“两两点积方阵”对比（A.14.3）：XᵀX、XXᵀ、QKᵀ 长得像，回答的问题完全不同——QKᵀ 是 Gram 矩阵的学习版，不是协方差。

　　读完应能讲清两件事：归一化公式里“除以标准差”除的是什么；注意力打分矩阵与协方差矩阵像在哪、差在哪。

A.14.1 方差与标准差：一组数离均值有多远

　　两组数据平均值相同，性质可能天差地别：一组全挤在均值旁边，一组东一个西一个。只说“平均是多少”装不下这个差别，还需要一把“离散程度”的尺子。自然的想法是把每个数与均值的偏差加起来，但正负偏差会互相抵消（偏左 2 和偏右 2 相加得 0），所以先平方再平均——平方后偏差都是正数，而且偏得越远惩罚越重。这就是方差：

\[ \operatorname{Var}(x) = \frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2, \qquad \mu = \frac{1}{n}\sum_{i=1}^{n} x_i \tag{1} \]
公式 (1)：方差＝偏差平方的平均。符号说明：\(x_i\) 是第 \(i\) 个数据；\(n\) 是数据个数；\(\mu\) 是均值；\(\sum\) 是求和。严谨的无偏估计分母用 \(n-1\)，数据量大时与 \(n\) 几乎无差，本书不再区分。

　　方差有个小毛病：单位被平方了。身高的单位是厘米，方差的单位就是“平方厘米”，没法直接和身高比较。开平方把单位换回来，得到标准差：

\[ \sigma = \sqrt{\operatorname{Var}(x)} \tag{2} \]
公式 (2)：标准差＝方差开平方，单位与原始数据一致。符号说明：\(\sigma\) 是标准差，读作“这组数典型地偏离均值多远”。

图 1：方差大小的直觉对比。两组数据均值相同（红色虚线），上面一组全挤在均值附近（σ 小），下面一组摊得开（σ 大）。方差大不代表均值大，只代表波动大。

　　本书里方差与标准差出场最多的地方是归一化。LayerNorm 对每行向量“减均值、除以标准差”，把数据拉回均值为 0、波动为 1 的温和区间；RMSNorm 更省事，不减均值，直接除以均方根（root mean square，各分量平方平均再开根号），把典型量级压回 1 附近（4.4 节、5.1 节）。训练稳定性也靠方差把控：初始化权重时按方差控制量级，让每层的输入输出波动既不萎缩消失也不累积爆炸（第 7 章）。

A.14.2 协方差与协方差矩阵：两个变量怎么“一起变”

　　方差只管一个变量自己的散布。换成两个变量——比如一批人的身高与体重——更有意义的问题是：它们怎么一起动？x 偏大的时候 y 是不是也偏大？把两个偏差乘起来再平均，就是协方差：

\[ \operatorname{Cov}(x, y) = \frac{1}{n}\sum_{i=1}^{n}(x_i - \mu_x)(y_i - \mu_y) \tag{3} \]
公式 (3)：协方差＝两个变量偏差的乘积的平均。符号说明：\(x_i, y_i\) 是第 \(i\) 个样本的两个变量；\(\mu_x, \mu_y\) 是各自均值。结果为正：x 大时 y 倾向也大（正相关）；为负：一个涨另一个跌（负相关）；接近 0：各走各的（线性无关）。
原创示意图 · 非论文原图
图 2：协方差的三种形态。点云斜向上，协方差为正；乱成一团，接近 0；斜向下，为负。注意协方差只捕捉“直线式的一起变”，曲线式的关联它测不出来。

　　变量一多，就要两两配对算协方差。把 n 个样本、d 个变量排成矩阵 X（n 行 d 列），先逐列减去均值（这步叫中心化，记作 \(X_c\)），再做矩阵乘法，所有协方差一次算齐：

\[ C = \frac{1}{n-1}\, X_c^{\top} X_c \tag{4} \]
公式 (4)：协方差矩阵。符号说明：\(X_c\) 是中心化后的数据矩阵（n 个样本 × d 个变量，下标 c 表示 centered，已减均值）；\(X_c^{\top}\) 是它的转置；\(C\) 是 d×d 方阵，第 (i, j) 格是第 i 维与第 j 维的协方差。两个特征：对角线上是各变量自己的方差；矩阵必然对称（i 与 j 的协方差等于 j 与 i 的）。分母 \(n-1\) 是样本无偏估计的惯例。

　　说句实话：协方差矩阵在 LLM 主干里并不直接出场，它属于 PCA、白化那一路的经典方法。讲它是为了下一节的对比——很多人看到注意力的 QKᵀ 会脱口而出“这不就是协方差矩阵吗”，值得把这层误会拆开。

A.14.3 三个“两两点积方阵”：XᵀX、XXᵀ、QKᵀ

　　三个矩阵乘积摆在一起：\(X_c^{\top} X_c\)、\(X X^{\top}\)、\(Q K^{\top}\)。写法像亲兄弟，回答的问题却完全不同。关键在于乘的方向：数据矩阵 X 是“n 个样本 × d 个特征”，转置放左边还是右边，决定了乘出来的方阵在比较什么。

　　XᵀX（d×d）：特征×特征，回答“两个维度怎么一起变”。转置放左边，样本维被消掉，留下特征维。第 (i, j) 格是“第 i 维特征与第 j 维特征在所有样本上的联动程度”——中心化之后，它就是协方差矩阵。它是数据的固定统计量：数据给定，矩阵就定了，没有可学的东西。

　　XXᵀ（n×n）：样本×样本，回答“两个样本有多像”。转置放右边，特征维被消掉，留下样本维。第 (i, j) 格是“第 i 个样本的向量与第 j 个样本的向量的点积”——点积越大越相似（A.2 节）。这个矩阵在机器学习里叫 Gram 矩阵（格拉姆矩阵），是核矩阵的最简形态。注意它不做中心化，是未中心化的二阶矩。

　　QKᵀ（n×n）：token×token，回答“第 i 个 token 该听第 j 个 token 多少”。4.3 节图 6 那张打分矩阵就是它。把它展开看：

\[ Q K^{\top} = (X W_Q)(X W_K)^{\top} = X \, W_Q W_K^{\top} X^{\top} \tag{5} \]
公式 (5)：注意力打分矩阵的展开。符号说明：\(X\) 是输入矩阵（n 个 token × d 维）；\(W_Q, W_K\) 是训练学出来的投影矩阵；\(Q K^{\top}\) 是 n×n 方阵，第 (i, j) 格是“token i 的 query 与 token j 的 key 的匹配分”。

　　形状上它和 Gram 矩阵一样是“样本×样本的点积方阵”，但中间夹着一个学出来的 \(W_Q W_K^{\top}\)——相似度的度量标准本身是可训练的。模型在训练中自己决定“按什么标准算像”：哪些维度该放大、哪些该压掉、哪些组合值得关注。换句话说，Gram 矩阵用天生的点积比相似，QKᵀ 用学出来的点积比相似。只有当 \(W_Q = W_K = I\)（单位矩阵，不做任何投影）时，QKᵀ 才退化成普通的 Gram 矩阵。

　　回到开头的疑问：QKᵀ 与协方差矩阵是不是一回事？不是，差别有三层。其一，比较对象不同：协方差矩阵比的是特征×特征，QKᵀ 比的是 token×token。其二，预处理不同：协方差必须先减均值（中心化），QKᵀ 不减。其三，来源不同：协方差是数据的固定统计量，QKᵀ 的度量标准 \(W_Q, W_K\) 是训练产物。另外还有两个形态差别：协方差矩阵必然对称，QKᵀ 一般不对称（query 与 key 走不同投影，i 听 j 的分不等于 j 听 i 的分），加上因果掩码后更是下三角阵；协方差矩阵的对角线是“方差”，QKᵀ 的对角线只是“token 自己听自己的分”，没有方差含义。
