4.4 前馈网络、残差连接与层归一化：注意力的三位搭档

本页范围：第 4 章第 4 节　|　整理时间：2026-09-29

快速浏览

核心问题多头注意力算完「谁看谁」之后，一层 Transformer 还差哪些部件，才能叠到 6 层甚至上百层还训得动？
本节主张每个子层都配三位搭档：FFN 把每个位置的信息独立加工一遍，残差连接给信息和梯度留一条直达通道，层归一化把数值分布拉回标准形态。三者按固定套路包裹每一个子层。
一句话结论注意力管搬运信息，FFN 管加工信息，残差连接与层归一化管深层堆叠的稳定性，四者合体才是完整的一层 Transformer。
关键词
FFN逐位置残差连接层归一化DropoutPost-LN

　　前两节把注意力讲透了，但一层 Transformer 不只有注意力。原论文的每一层里，注意力之外还站着三位搭档：前馈网络、残差连接、层归一化。缺了它们，6 层都叠不稳，更别说今天 LLM 的上百层。本节逐个讲清它们各管什么，最后把零件装回整机：

  1. FFN：每个位置的独立思考（4.4.1）：注意力管搬运，FFN 管加工，512 → 2048 → 512 的两段变换拿走了一层约三分之二的参数；
  2. 残差连接：梯度的高速公路（4.4.2）：输入原样加回输出，正向信号不丢、反向梯度不衰减，这是深层堆叠的前提；
  3. 层归一化：给数值分布上缰绳（4.4.3）：把每个 token 的 512 个分量折算成均值 0、方差 1，再用可学习的 γ、β 把尺度学回来；
  4. 三件套如何拼成完整的一层（4.4.4）：dropout、残差相加、层归一化按固定顺序包裹每个子层，张量形状全程不变。

　　读完本节，「一层 Transformer」在你眼里应该是一个完整配方，而不再只是注意力。

4.4.1 FFN：每个位置的独立思考

　　前两节的多头注意力解决的是 token 之间的信息交换：每个位置看看别的位置，把有用的信息加权搬回来。但搬回来的只是原料，还需要一道加工工序，这就是每层第二个子层——逐位置前馈网络（Position-wise Feed-Forward Network，FFN）要干的活。

　　把一层 Transformer 想象成一次部门例会。注意力阶段是开会：每个人（token）听别人发言，把和自己相关的要点记下来。FFN 阶段是散会后各自回工位：每个人关起门来，把记下的笔记独立整理消化，形成自己的新认识。下一层再开一次会、再整理一次，如此往复六轮（原论文 \(N=6\)）。

\[ \mathrm{FFN}(x)=\max(0,\,xW_{1}+b_{1})\,W_{2}+b_{2} \tag{1} \]
公式 (1)：原论文 3.3 节。两个线性变换中间夹一个 ReLU 激活，\(x\) 是某个位置的 512 维向量。符号说明：\(W_1,b_1\) 是第一个线性变换的权重与偏置（把 512 维放大到 2048 维）；\(\max(0,\cdot)\) 是 ReLU 激活，逐分量把负数置 0；\(W_2,b_2\) 是第二个线性变换的权重与偏置（把 2048 维压回 512 维）；四个都是训练出来的参数，同一层内所有位置共用。

　　把公式 (1) 按运算顺序拆开：

  • \(xW_{1}+b_{1}\)：把 512 维放大到 2048 维（\(W_{1}\) 形状 \(512\times2048\)），维度膨胀 4 倍；
  • \(\max(0,\cdot)\)：ReLU 激活，负数一律砍成 0，像一排闸门，只放被激活的特征通过；
  • \(\cdot\,W_{2}+b_{2}\)：把 2048 维压回 512 维（\(W_{2}\) 形状 \(2048\times512\)），保证输出还能接回主干。

　　落到具体数字。设一句话有 \(n=10\) 个 token，整个 FFN 的形状变化是：

步骤运算张量形状
输入\(x\)\((10,\ 512)\)
放大 4 倍\(xW_{1}+b_{1}\)\((10,\ 2048)\)
闸门筛选\(\max(0,\cdot)\)\((10,\ 2048)\)
压回原宽\(\cdot\,W_{2}+b_{2}\)\((10,\ 512)\)

　　参数量也能算出来：\(W_{1}\) 与 \(W_{2}\) 各有 \(512\times2048\approx105\) 万个权重，连偏置合计约 210 万个参数。作为对比，4.2 节多头注意力子层的四个投影矩阵合计约 105 万个参数——一层里约三分之二的参数在 FFN 里。说 FFN 是模型的「知识仓库」并不夸张：有研究把 FFN 的神经元解释为一条条 key-value 记忆，认为模型记住的事实知识主要存在这里（Geva et al., 2021）。

逐位置 Position-wise position-wise = 对序列中每个位置分别施加同一个网络

原论文说 FFN「分别且相同地应用于每个位置」：10 个 token 就是 10 次独立计算，用的是同一组 \(W_{1},W_{2}\)（层与层之间参数不同）。它不看任何别的位置，只处理当前位置自己的 512 维向量。原论文还给出一种等效看法：两个核大小为 1 的卷积。

为什么偏偏膨胀 4 倍（\(2048/512\)）？原论文没有解释，这是工程经验的选择，但影响深远：后来的 GPT 系模型大多沿用 4 倍膨胀这个比例。
注意力负责搬运，FFN 负责加工。注意力的输出是每个位置从各处借来的信息的混合物，FFN 对这份混合物做非线性变换，提炼出新特征。两个子层交替，就是「交流一次、思考一次」。

　　所以这步在干嘛：把每个 token 刚收集来的信息，先摊到 2048 维的大工作台上筛选（ReLU 闸门），再压回 512 维的精华——每个位置被独立消化了一遍。

4.4.2 残差连接：梯度的高速公路

　　原论文把 6 个完全相同的层叠在一起，今天的模型动辄几十上百层。一个朴素的问题随之出现：信息每经过一层就被改写一次，叠得越多，底层的输入信号和传回底层的梯度，都越容易在层层变换中走样甚至消失——网络越深越训不动。

　　这就像传话游戏：一句话经 50 个人依次转述，传到最后往往面目全非。如果改一下规则——每个人除了转述自己的版本，还必须把听到的原话抄一份一起递下去——那无论传多少棒，最初的那句话都丢不了。残差连接（Residual Connection）改的就是这个规则。

\[ \mathrm{LayerNorm}\big(x+\mathrm{Sublayer}(x)\big) \tag{2} \]
公式 (2)：原论文 3.1 节给定的子层输出。输入 \(x\) 不经任何变换，直接加到子层自己的输出上，再做层归一化。符号说明：\(\mathrm{Sublayer}(x)\) 是子层（多头注意力或 FFN）对 \(x\) 的变换；\(\mathrm{LayerNorm}\) 是层归一化，即公式 (3) 的完整操作；相加要求 \(x\) 与 \(\mathrm{Sublayer}(x)\) 形状一致。

　　从梯度视角看，加法对梯度是原样放行的：若 \(y=x+F(x)\)，则 \(\partial y/\partial x=1+\partial F/\partial x\)。无论 \(\partial F/\partial x\) 多小，那个常数 \(1\) 都在，梯度总有一条不衰减的通道直达浅层。这就是「高速公路」的含义：残差旁路上的梯度不堵车，几十层的网络才训得动。这一思想源自 ResNet（He et al., 2016），原论文把它借用到每个子层周围。

残差连接带来一条硬约束：相加要求两边形状一致。原论文为此把模型中所有子层以及嵌入层的输出维度统一成 \(d_{\mathrm{model}}=512\)（3.1 节），这就是 512 这个数字在架构里反复出现的原因之一。

　　所以这步在干嘛：子层只负责学「增量」，原始信息走旁边的直达通道原样下传；正向传信号不丢失，反向传梯度不衰减。

4.4.3 层归一化：给数值分布上缰绳

　　残差相加解决「深」，还有一个「稳」的问题。训练过程中，每个 token 的 512 维向量的数值幅度会随层数和参数更新不断漂移：有的分量冲到几十，有的缩在零附近。数值分布忽胖忽瘦，后续子层就要不停适应新尺度，训练像开一辆方向盘发抖的车。层归一化（Layer Normalization，LN）的作用是给这辆车上缰绳。

层归一化 Layer Normalization normalize = 把数据折算到统一的标准尺度

LN 对每一个 token 的 512 维向量单独做两件事：先减去均值、除以标准差，把这组数折算成均值 0、方差 1 的标准形态；再乘一个可学习的缩放 \(\gamma\)、加一个可学习的平移 \(\beta\)，让模型自己决定标准形态之后最合适的尺度和位置。统计量在「同一个 token 的 512 个分量」上计算，与序列长短、批次大小无关。

\[ \mathrm{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^{2}+\epsilon}}+\beta,\qquad \mu=\frac{1}{d}\sum_{i=1}^{d}x_{i},\quad \sigma^{2}=\frac{1}{d}\sum_{i=1}^{d}(x_{i}-\mu)^{2} \tag{3} \]
公式 (3)：\(d=d_{\mathrm{model}}=512\)，\(\epsilon\) 是防除零的小常数；\(\gamma,\beta\) 为可学习参数（LN 原始论文：Ba et al., 2016）。符号说明：\(x\) 是某个 token 的 \(d\) 维向量，\(x_i\) 是它的第 \(i\) 个分量；\(\mu\) 与 \(\sigma^2\) 分别是这 \(d\) 个分量的均值与方差，统计只在同一 token 内部进行；\(\odot\) 表示逐分量相乘，\(\gamma,\beta\) 也逐分量作用，每个维度各有一个缩放和一个平移参数。

　　拿一个 4 维小向量 \(x=(2,4,4,6)\) 走一遍。均值 \(\mu=4\)，方差 \(\sigma^{2}=\big((2-4)^{2}+0+0+(6-4)^{2}\big)/4=2\)，标准差 \(\sqrt{2}\approx1.41\)。标准化后得到 \((-1.41,\ 0,\ 0,\ 1.41)\)：偏大的 6 变成 \(+1.41\)，偏小的 2 变成 \(-1.41\)，中间值归零。最后乘 \(\gamma\)、加 \(\beta\)（训练中学会的缩放与平移），就是 LN 的输出。512 维时算法一模一样，只是统计量在 512 个数上算。

　　为什么还要 \(\gamma,\beta\)？一律标准化会抹掉「这个 token 本来信号更强」这类幅度信息，模型未必想要人人均值 0。\(\gamma,\beta\) 让网络把有用的尺度和偏移学回来——先帮你稳住，再给你自由。

和 BatchNorm 的区别一句话带过：BN 在一个批次内、按特征维跨样本算统计量；LN 在同一个样本内部、按特征分量算统计量。序列长度可变、批次为 1 的场景下 BN 很难用，这正是 Transformer 选 LN 的原因（Ba et al., 2016）。

　　所以这步在干嘛：每经过一个子层，就把每个 token 的数值重新归置到标准形态，再按学来的尺度微调，让下一层永远面对分布稳定的输入。

4.4.4 三件套如何拼成完整的一层

　　现在把零件装起来。原论文 3.1 节与 5.4 节合起来给出了一层编码器的固定组装套路：每个子层（多头注意力、FFN）都被同样三件套包裹——

  1. 子层计算：\(\mathrm{Sublayer}(x)\)；
  2. 施加 dropout：训练时把子层输出中约 10% 的数值随机置零（\(P_{drop}=0.1\)）；
  3. 残差相加：把子层输入 \(x\) 原样加回来；
  4. 层归一化：对相加结果做 LN，得到这一子层的最终输出。

　　第 2 步来自 5.4 节的 residual dropout：原论文明确说在每个子层的输出上应用 dropout，「在将其添加到子层输入并进行归一化之前」；嵌入与位置编码之和进第一层前同样施加。所以这个固定顺序可以写成 \(\mathrm{LN}\big(x+\mathrm{Dropout}(\mathrm{Sublayer}(x))\big)\)。

Dropout 随机丢弃 drop out = 训练时随机让一部分数值「缺席」

dropout 在训练时以概率 \(p\) 把张量中的一些数值随机置零（基础模型 \(p=0.1\)），迫使网络不能把希望寄托在某几个特定数值上，要学出更分散、更稳健的特征；推理时关闭，全量数值参与计算。

图示：原论文 Post-LN 顺序下，一层编码器的完整数据流。两个子层各自被三件套包裹，张量形状全程 (n, 512) 不变。

　　注意图里一个贯穿始终的事实：从输入到输出，张量形状始终是 \((n,512)\)。残差相加能成立靠它（形状一致才能相加），层与层之间能无限堆叠也靠它——这一层的输出形状和输入一样，下一层原样接上即可。

演进预告：原论文这种「先相加、后归一化」的顺序叫 Post-LN。后来的研究发现，把归一化挪到子层输入侧（Pre-LN，即 \(x+\mathrm{Sublayer}(\mathrm{LN}(x))\)）在深层模型中训练更稳定，甚至不必依赖学习率预热（Xiong et al., 2020）；LN 本身被简化成 RMSNorm，FFN 的 ReLU 也被 SwiGLU 取代。这些现代变体是第 5 章的主题，5.1 节细讲。

　　所以这一层在干嘛：token 们先开会交换信息（注意力），散会后各自整理消化（FFN）；残差旁路保证信息与梯度畅通，LN 与 dropout 把数值和训练都约束在稳定轨道上。六层叠加，就是「交流—思考—再交流—再思考」的六轮循环。

🧭本节要点回顾
注意力和 FFN 在一层里如何分工？
注意力负责 token 之间的信息搬运（每个位置加权收集别处的信息），FFN 对每个位置的 512 维向量独立做 512 → 2048 → 512 的非线性加工。一层 = 交流一次 + 思考一次。
深层 Transformer 为什么离不开残差连接？
加法让正向的原始信息和反向的梯度都有一条不衰减的直达通道（\(\partial y/\partial x\) 中恒含常数 1）。没有它，几十层堆叠会让信号与梯度在层层变换中走样消失。
层归一化在每个 token 上具体做了什么？
对该 token 的 512 个分量减去均值、除以标准差，折算成均值 0、方差 1 的标准形态，再乘可学习的 \(\gamma\)、加可学习的 \(\beta\) 微调尺度，让每层输入的数值分布保持稳定。
