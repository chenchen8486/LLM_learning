核心问题注意力本身对顺序“无感”，模型怎么知道每个 token 排在第几位？
本节主张绝对位置编码给每个位置分配一个专属向量，与词向量相加后一并送入模型。两种经典做法：人工设计波形的正弦位置编码（原始 Transformer）和交给训练自己学的可学习位置编码（GPT 系列）。
一句话结论两者效果几乎相同：正弦省参数、理论上可外推，可学习零设计成本但外推差；它们都是“绝对”方案，后来共同让位于相对位置编码。

3.3.1 把位置“写”进向量

　　上一节看到，每个 token 经过 Embedding 层变成一个 \(d_{\mathrm{model}}\) 维向量。但这个向量只回答了“这个词是什么”，没有回答“它排在第几位”。而自注意力（第 4 章细讲）在计算时对所有位置一视同仁：把输入序列打乱重排，每个位置算出的注意力结果不会有任何变化。换句话说，裸的注意力机制对顺序是“无感”的，“狗咬了人”和“人咬了狗”在它眼里是同一袋向量。

　　RNN 按顺序逐个读入，顺序信息天然存在；Transformer 一次性并行读入全部 token，就必须把位置信息显式注入进去。原论文（Vaswani et al., 2017）的做法非常直接：给每个位置 pos 也配一个 \(d_{\mathrm{model}}\) 维向量 \(\boldsymbol{p}_{pos}\)，与词向量相加后送入网络：

\[ \boldsymbol{h}_{pos} = \boldsymbol{e}_{token} + \boldsymbol{p}_{pos} \tag{1} \]
公式 (1)：输入向量 = 词向量 + 位置向量，两者维度相同才能逐维相加。这个相加只在编码器/解码器堆栈的最底部做一次。

　　相加为什么不会互相干扰？直觉上，\(d_{\mathrm{model}}\) 维空间足够大，语义信息和位置信息像写在同一张纸不同图层上的内容，后续的线性变换可以把两者分别读出来。就像信封上同时印着收信人地址（内容）和邮戳（时间地点），邮局两样都读得到。

位置编码 Positional Encoding positional = 位置的；encoding = 编码

位置编码是为序列中每个位置准备的一个向量，与词向量相加后告诉模型“这个 token 排在第几位”。它分两大类：本节讲的绝对位置编码给每个位置一个独立编号（正弦波形或查表学习）；3.4 节要讲的相对位置编码则直接告诉注意力“两个 token 相距多远”。

就像剧院票根上的座位号：观众（token）是谁是一回事，坐在第几排第几座是另一回事，两样信息合在一起，检票员才知道该把你往哪儿领。
两个容易忽略的工程细节：原论文在“词向量 + 位置编码”相加之后还会施加一次 dropout（基础模型 \(P_{drop} = 0.1\)），再送入第一层子层；另外位置编码必须与词向量同为 \(d_{\mathrm{model}}\) 维，否则无法逐维相加。

3.3.2 正弦位置编码：给每个维度配一把不同刻度的尺子

　　正弦位置编码是人工设计的一套固定波形。先给直觉：想象墙上有 \(d_{\mathrm{model}}/2\) 根转速各不相同的指针，第一根每 6 步多就转完一圈，第二根每 63 步转一圈，越往后越慢，最后一根要 6 万多步才转完一圈。位置每前进一格，所有指针同时按各自的速度转动一点。于是任意一个位置，都对应一组独一无二的“钟面读数”——这组读数就是这个位置的编码。

　　把每根指针的读数写成公式，就是原论文 §3.5 的定义：

\[ PE_{(pos,\,2i)} = \sin\!\left(\frac{pos}{10000^{\,2i/d_{\mathrm{model}}}}\right) \qquad PE_{(pos,\,2i+1)} = \cos\!\left(\frac{pos}{10000^{\,2i/d_{\mathrm{model}}}}\right) \tag{2} \]
公式 (2)：pos 是位置（0, 1, 2, …），i 是维度对编号。偶数维用 sin、奇数维用 cos，同一对的两个读数相当于一根指针的横、纵坐标。

　　每个维度对的角频率是 \(\omega_i = 1/10000^{2i/d_{\mathrm{model}}}\)，对应波长 \(\lambda_i = 2\pi \cdot 10000^{2i/d_{\mathrm{model}}}\)。按原论文的说法，这些波长从 \(2\pi\) 到 \(10000 \cdot 2\pi\) 构成几何级数：最短约 6.3 步，最长约 6.3 万步。短波长的维度转得快，相邻两个位置的读数差别很大，负责精确定位；长波长的维度转得极慢，走上几百步几乎不动，负责标记“大致在哪一段”。

　　这套设计很像钟表：秒针（短波长）告诉你精确的秒，时针（长波长）告诉你大致几点，单看任何一根都不够，合起来才唯一确定时刻。也可以把它看成多进制计数器的连续光滑版本：二进制计数里个位每步翻转、高位很久才变一次，正弦编码用平滑的波形实现了同样的“快慢搭配”。

原创示意图 · 非论文原图
图示：正弦位置编码中三个维度的波形（仅画 sin 分量，纵轴为该维度的编码取值）。低维振荡快、精细区分相邻位置；高维近乎水平、标记全局范围。全部维度叠加后，每个位置得到独一无二的编码组合。

　　原论文选择正弦函数还有一个更技术性的理由：对任意固定偏移 k，\(PE_{pos+k}\) 可以写成 \(PE_{pos}\) 的线性函数。利用三角恒等式，对每个维度对有：

\[ \sin(\omega_i(pos+k)) = \cos(\omega_i k)\sin(\omega_i pos) + \sin(\omega_i k)\cos(\omega_i pos) \tag{3} \] \[ \cos(\omega_i(pos+k)) = -\sin(\omega_i k)\sin(\omega_i pos) + \cos(\omega_i k)\cos(\omega_i pos) \]
公式 (3)：展开系数只含 k 不含 pos，相当于在每个维度对上施加一个只由 k 决定的 2×2 旋转。知道某位置的编码和偏移量 k，一次固定的线性变换就能推出 k 步之外的编码。

　　这意味着“相对距离”被直接编码进了向量结构：模型想做“往前数 3 个位置”这类操作时，学到的只是一个固定的线性变换，而不必从两个毫无规律的编号里猜关系。原论文正是据此推断，正弦编码能让模型更容易学会按相对位置做注意力。

3.3.3 可学习位置编码：交给训练自己学

　　另一条路线干脆不做任何人工设计：给位置建一张表，让模型自己学。以 GPT 系列为代表的可学习位置编码（learned positional embedding）维护一个 max_len × d_model 的参数矩阵，随机初始化，像词向量一样随训练更新。位置 pos 的编码就是矩阵的第 pos 行，查表即得。

　　这种把位置“背下来”的做法简单直接，效果一点不差。原论文在机器翻译任务上对比过两种方案：

两种绝对位置编码在建模能力上没有实质差距。原论文最终选正弦，不是因为它效果更好，而是因为它不增加任何参数，且有望外推到比训练时更长的序列；GPT 系选可学习，是因为它零设计成本、实现最简单，而当时的上下文长度（GPT-1 为 512 个 token）根本用不到外推。

3.3.4 共同的局限：绝对位置的天花板

　　无论正弦还是可学习，思路都是给每个位置发一张“绝对门牌号”，再指望模型自己从门牌号里推出相对关系。这个思路有两个绕不开的短板：

  • 间接性：注意力真正关心的是“两个 token 相距多远”，而绝对编码只告诉模型“各自坐在哪”，相对距离要靠模型从两个向量的相互作用里间接算出来；
  • 外推落空：原论文期望正弦编码能外推到更长序列，但后来的系统实验表明，无论正弦还是可学习，输入一旦超过训练长度，模型表现都会明显下滑（Press et al., 2021）。

　　既然“先发绝对编号、再间接推相对”绕了弯路，何不直接告诉注意力“你们相距 k 步”？这就是相对位置编码的思路：RoPE 把相对距离以旋转向量的方式注入注意力计算，ALiBi 干脆按距离给注意力分数加惩罚。它们是现代 LLM 的主流选择，也是下一节的主题。

🧭本节要点回顾
为什么自注意力必须额外注入位置信息？
注意力计算对输入顺序是排列不变的：打乱 token 顺序，每个位置的计算结果不变。没有位置编码，模型分不清语序不同的两句话。把位置向量与词向量相加，是最直接的注入方式。
正弦编码为什么让不同维度用 \(2\pi\) 到 \(10000 \cdot 2\pi\) 的不同波长？
短波长维度精细区分相邻位置，长波长维度标记全局范围，几何级数的波长组合让每个位置的编码独一无二；且对固定偏移 k，\(PE_{pos+k}\) 是 \(PE_{pos}\) 的线性函数，方便模型学相对位置。
正弦和可学习位置编码该选哪个？
原论文实测两者效果几乎相同（BLEU 25.8 对 25.7）。正弦省参数、理论上可外推；可学习零设计成本但超出训练长度就失效。如今两者都让位于相对位置编码（RoPE、ALiBi）。

动手验证

　　minimind 没有使用本节的绝对位置编码，它直接使用 RoPE（3.4 节的主题）。但它的频率预计算与本节公式一脉相承：model/model_minimind.py 中 precompute_freqs_cis() 用 freqs = 1 / (rope_base ** (2i/d)) 生成同样按几何级数排开的角频率，只是不再与词向量相加，而是按位置旋转注意力里的 Q/K 向量（apply_rotary_pos_emb()）。读这两段代码时，可对照本节公式 (2) 的角频率 \(\omega_i\)。代码出处：minimind 工程，Apache 2.0。

　　也可以用十几行 NumPy 亲手复现本节的波形图（需安装 numpy 与 matplotlib）：

import numpy as np
import matplotlib.pyplot as plt

pos = np.arange(100)
for exp in [0.0, 0.25, 1.0]:      # 对应公式中的 2i/d_model
    omega = 1 / 10000**exp        # 角频率
    plt.plot(pos, np.sin(pos * omega), label=f"2i/d={exp}")
plt.legend(); plt.show()

　　预期看到与本节示意图一致的三条曲线：exp=0 的维度高频振荡，exp=0.25 的维度约 1.6 个周期，exp=1 的维度在 100 步内几乎是一条直线——这正是正弦编码“快慢搭配”的直观体现。
