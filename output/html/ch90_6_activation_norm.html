A.6 激活函数与归一化：让网络既会弯、又稳得住

本页范围：附录 A 第 6 节　|　整理时间：2026-09-30

快速浏览

核心问题矩阵乘矩阵还是矩阵，一百层线性叠起来和一层没区别——深度的意义从哪来？另外，几十层之间数值尺度一路漂移，训练怎么稳得住？
本节主张激活函数逐元素施加非线性，是“深度”真正起效的原因；归一化把每层输入的均值和波动拉回标准尺度，是深层网络训得动的工程基石。LLM 的选型很集中：激活用 SwiGLU（门是 SiLU），归一化用 RMSNorm。
一句话结论ReLU 管“会不会弯”，归一化管“稳不稳”——FFN 里的激活函数和每个子层旁的 Norm，分别对应 4.4 节与 5.1 节。
关键词
非线性ReLUGELUSiLU / SwiGLU均值与方差LayerNorm / RMSNorm

　　A.5 节讲了梯度怎么传，但有两个工程问题没解决。第一，如果每层只是矩阵乘法，层数再多也白搭——复合一千次线性变换，结果仍是一次线性变换。第二，数值在几十层之间传来传去，尺度会越放越大或越缩越小，梯度跟着失控。Transformer 对这两个问题的回答分别是：FFN 里的激活函数，和每个子层旁边的归一化层。本节把这两个小件讲透。

  1. 激活函数：没有它，一百层等于一层（A.6.1）：ReLU、GELU、SiLU 三条曲线，以及 SwiGLU 的门控思路；
  2. 均值、方差与归一化（A.6.2）：三个数的手算例子，LayerNorm 与 RMSNorm 的差别。

　　读完应能讲清两件事：非线性为什么是深度的前提，以及 RMSNorm 比 LayerNorm 少做了什么、为什么够用。

A.6.1 激活函数：没有它，一百层等于一层

　　矩阵乘法是线性的：输入放大两倍，输出也放大两倍；两次线性变换复合，等于一次新的线性变换（\(W_2(W_1 x) = (W_2 W_1) x\)）。这意味着一个只由矩阵乘法堆起来的网络，无论多少层，表达能力都等价于单层——学不出“弯曲的”规律。破解办法是在层与层之间插一个逐元素的非线性函数，这就是激活函数。它作用在向量的每个分量上，各自独立，不混合维度。

　　最经典的是 ReLU，规则一句话：负数归零，正数原样通过。

\[ \mathrm{ReLU}(x) = \max(0, x) \tag{1} \]
公式 (1)：ReLU（Rectified Linear Unit，修正线性单元）。符号说明：\(x\) 是向量某一个分量的数值；\(\max(0, x)\) 表示取 0 与 \(x\) 中较大者。它在 0 处有一个折点，正是这个折点提供了非线性。代价是负半轴一刀切，负区间的梯度恒为 0（见 A.5 节，梯度为 0 意味着参数收不到更新信号）。

　　LLM 更常用平滑版。GELU 与 SiLU 都在原点附近留了一段平滑的“下坡再抬头”，负区间不是死零，梯度处处可传。SiLU 的定义里出现 sigmoid（\(\sigma(x) = 1/(1+e^{-x})\)，把任意实数压进 0 到 1 的 S 形函数）：

\[ \mathrm{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}} \tag{2} \]
公式 (2)：SiLU（也叫 Swish）。符号说明：\(x\) 是分量数值；\(\sigma(x)\) 是 sigmoid 函数；\(e \approx 2.718\)。读法：用 sigmoid 当“阀门”，x 越大阀门越开（\(\sigma\) 趋近 1，输出接近 x），x 越负阀门越关（输出趋近 0），中间平滑过渡。GELU 形状几乎一样，只是用高斯累积分布函数当阀门，定义涉及积分，这里不展开。
原创示意图 · 非论文原图
图 1：三种激活函数。横轴是输入，纵轴是输出。ReLU（灰）在负半轴贴死 0；GELU（紫）与 SiLU（蓝）在原点附近平滑下凹、处处可导，正半轴三者都近似 y = x。

　　5.1 节的 SwiGLU 更进一步，走“门控”路线：把输入分两路，一路过 SiLU 当阀门，一路原样当内容，两路逐元素相乘再投影回去。阀门由数据自己决定开多大，比固定形状的激活函数多一层表达能力。minimind 与 LLaMA 系列的 FFN 用的都是它。

A.6.2 均值、方差与归一化

　　归一化要用到两个统计量。均值是数据的中心位置，方差是数据围绕中心波动的剧烈程度：

\[ \mu = \frac{1}{n} \sum_{i=1}^{n} x_i, \qquad \sigma^2 = \frac{1}{n} \sum_{i=1}^{n} (x_i - \mu)^2 \tag{3} \]
公式 (3)：均值与方差。符号说明：\(x_1, \dots, x_n\) 是一组数（比如一个向量的各分量，或一批样本）；\(\mu\) 是均值；\(\sigma^2\) 是方差，\(\sigma\) 开平方叫标准差，与原始数据同量纲。方差的读法：每个数离均值多远，距离平方再平均——平方是为了让正负偏差都算作“远”。

　　归一化就是把数据中心挪到 0、波动压到 1：

\[ \hat{x}_i = \frac{x_i - \mu}{\sigma} \tag{4} \]
公式 (4)：标准化（归一化）。符号说明：\(\hat{x}_i\) 是归一化后的值；其余符号同公式 (3)。变换之后，这组数的均值恰好为 0、标准差恰好为 1。拿三个数手算一遍：\([10, 20, 30]\) 的均值是 20、标准差约 8.16，归一化后得 \([-1.22, 0, 1.22]\)——中心到 0，波动到 1。

图 2：归一化前后对照。上面数轴是原始三个数 [10, 20, 30]，中心在 20；下面数轴是同一组数归一化后的位置 [−1.22, 0, 1.22]，中心到 0，三点相对间隔不变，只是整体平移并缩放。

　　Transformer 在每个子层旁放一个归一化层（4.4 节），用意是让每层拿到的输入尺度始终稳定：数值不随层数漂移，梯度的大小也就不会随层数失控（衔接 A.5 节的消失与爆炸问题）。归一化在向量自己的维度上做：每个 token 的向量各算各的均值方差，互不干扰。

　　原版 Transformer 用 LayerNorm，就是公式 (3)(4) 的完整版，外加可学习的缩放和平移参数。5.1 节讲的 RMSNorm 是它的精简版：不减均值、不算方差，只除以分量的均方根：

\[ \hat{x}_i = \frac{x_i}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \varepsilon}} \tag{5} \]
公式 (5)：RMSNorm（Root Mean Square Normalization）。符号说明：\(x\) 是一个 token 的向量，\(d\) 是它的维度；分母是所有分量平方的平均再开方（即均方根 RMS），\(\varepsilon\) 是防止除零的小常数（如 \(10^{-6}\)）；\(\hat{x}_i\) 是归一化后的分量。少了“减均值”这一步，计算更省，实测效果与 LayerNorm 相当，这是现代 LLM 普遍换用它的原因（5.1 节）。与 LayerNorm 相同，RMSNorm 外面也挂一个可学习的逐维度缩放参数。
