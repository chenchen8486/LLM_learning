核心问题如何设计一个完全基于注意力的编码器-解码器序列转换模型？
本文主张编码器/解码器均由堆叠自注意力层与位置级前馈层组成，用多头注意力实现多子空间关注。
一句话结论Transformer = 多头自注意力 + 残差连接 + 层归一化 + 位置编码。
关键词
编码器-解码器自注意力多头注意力前馈网络位置编码

大多数具有竞争力的神经序列转导模型都采用编码器-解码器结构。其中，编码器将输入符号表示序列 (x₁, ..., xₙ) 映射为连续表示序列 z = (z₁, ..., zₙ)。给定 z，解码器随后逐个元素地生成输出符号序列 (y₁, ..., yₘ)。每一步模型都是自回归的，即在生成下一个符号时，会将先前生成的符号作为额外输入。

图 1：Transformer 模型架构。左半部分为编码器，右半部分为解码器，均由堆叠的自注意力层和前馈层组成。

Transformer 遵循这一整体架构，在编码器和解码器中均使用堆叠的自注意力机制和逐点全连接层，分别如图 1 的左半部分和右半部分所示。

3.1 编码器和解码器堆栈

编码器

编码器由 N = 6 个相同层的堆栈组成。每一层包含两个子层。第一个子层是多头自注意力机制，第二个子层是简单的、位置逐点的全连接前馈网络。我们在每个子层周围采用残差连接，随后进行层归一化。也就是说，每个子层的输出为 LayerNorm(x + Sublayer(x))，其中 Sublayer(x) 是子层本身实现的函数。为便于这些残差连接，模型中的所有子层以及嵌入层都输出维度为 d_model = 512 的结果。

层归一化 Layer Normalization 对单个样本的所有特征做归一化，稳定深层网络训练

层归一化在每个样本内部沿特征维度计算均值和方差，然后做缩放和平移。与批归一化不同，它不依赖批次大小，适合序列模型和注意力机制。

就像把一份试卷上所有题目的得分先标准化，再看相对高低，避免某一道题分值过大影响总成绩。

解码器

解码器同样由 N = 6 个相同层的堆栈组成。除了每个编码器层中的两个子层外，解码器还插入第三个子层，该子层对编码器堆栈的输出执行多头注意力。与编码器类似，我们在每个子层周围采用残差连接，随后进行层归一化。

我们还修改了解码器堆栈中的自注意力子层，以防止位置关注后续位置。这种掩码操作，结合输出嵌入偏移一个位置的事实，确保对位置 i 的预测只能依赖于小于 i 的位置上的已知输出。

解码器掩码的关键约束：位置 i 不能"看到"位置 > i 的输出，这是保持自回归生成的根本。实现方式是把 softmax 输入中非法连接对应的值设为 −∞。

3.2 注意力

注意力函数可以描述为将查询和一组键值对映射到输出，其中查询、键、值和输出均为向量。输出计算为值的加权和，其中每个值的权重由查询与对应键的兼容性函数计算得出。

图 2：（左）缩放点积注意力。（右）多头注意力由多个并行运行的注意力层组成。

3.2.1 缩放点积注意力

我们将这种特定的注意力机制称为"缩放点积注意力"（图 2）。其输入包括维度为 d_k 的查询和键，以及维度为 d_v 的值。我们计算查询与所有键的点积，每个结果除以 √d_k，然后应用 softmax 函数来获得值的权重。

在实际应用中，我们同时对一组查询计算注意力函数，这些查询被组合成一个矩阵 Q。键和值也分别组合成矩阵 K 和 V。输出矩阵的计算方式如下：

\[ \mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V \tag{1} \]
公式 (1)：缩放点积注意力。先算 Query 与 Key 的相似度，缩放后用 softmax 归一化，再对 Value 做加权求和。

两种最常用的注意力函数是加性注意力和点积（乘法）注意力。点积注意力与我们的算法相同，只是缺少缩放因子 1/√d_k。加性注意力则使用一个带单隐藏层的前馈网络来计算兼容性函数。虽然两者在理论复杂度上相似，但点积注意力在实践中更快且更节省空间，因为它可以利用高度优化的矩阵乘法代码实现。

对于较小的 d_k 值，两种机制表现相似；但对于较大的 d_k 值，加性注意力优于未缩放的点积注意力。我们推测，当 d_k 较大时，点积的数值会变得很大，从而将 softmax 函数推入梯度极小的区域。为了抵消这种影响，我们通过 1/√d_k 来缩放点积。

为什么要缩放？当 d_k 很大时，点积值幅度会变大，softmax 进入梯度极小的饱和区。除以 √d_k 相当于对点积做方差归一化，保持梯度稳定。

3.2.2 多头注意力

与其使用 d_model 维的键、值和查询来执行单一的注意力函数，我们发现将查询、键和值分别通过不同的、可学习的线性投影 h 次，投影到 d_k、d_k 和 d_v 维度是有益的。然后，我们对这些投影后的查询、键和值的每个版本并行执行注意力函数，得到 d_v 维的输出值。这些输出值被拼接起来，并再次进行投影，得到最终的值，如图 2 所示。

多头注意力允许模型在不同位置共同关注来自不同表示子空间的信息。使用单个注意力头时，平均操作会抑制这种能力。

\[ \mathrm{MultiHead}(Q, K, V) = \mathrm{Concat}(\mathrm{head}_1, ..., \mathrm{head}_h)W^O \] \[ \mathrm{where~head}_i = \mathrm{Attention}(QW_i^Q, KW_i^K, VW_i^V) \]
多头注意力：把 Q/K/V 投影到多个低维子空间，各自做缩放点积注意力，再把结果拼接并投影。

其中，投影矩阵为 W_i^Q ∈ ℝ^(d_model × d_k)、W_i^K ∈ ℝ^(d_model × d_k)、W_i^V ∈ ℝ^(d_model × d_v) 和 W^O ∈ ℝ^(h·d_v × d_model)。

在本工作中，我们使用了 h = 8 个并行注意力层，即注意力头。对于每个头，我们设置 d_k = d_v = d_model / h = 64。由于每个头的维度降低，总计算成本与使用全维度的单头注意力相似。

3.2.3 注意力在模型中的应用

Transformer 以三种不同方式使用多头注意力：

  • 编码器-解码器注意力：查询来自前一个解码器层，而记忆键和值来自编码器的输出。这使得解码器中的每个位置都能关注输入序列中的所有位置。这模仿了序列到序列模型中典型的编码器-解码器注意力机制。
  • 编码器自注意力：在自注意力层中，所有键、值和查询都来自同一位置，即编码器中前一层的输出。编码器中的每个位置都能关注编码器前一层的所有位置。
  • 解码器自注意力（掩码）：解码器中的自注意力层允许解码器中的每个位置关注解码器中直到该位置（包括该位置）的所有位置。我们通过在缩放点积注意力中屏蔽（设置为 −∞）softmax 输入中所有对应非法连接的值来实现这一点。参见图 2。

Key（键）

3.3 位置级前馈网络

除了注意力子层外，编码器和解码器中的每一层都包含一个全连接的前馈网络，该网络分别且相同地应用于每个位置。它由两个线性变换组成，中间有一个 ReLU 激活函数。

\[ \mathrm{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2 \tag{2} \]
公式 (2)：位置级前馈网络。对同一位置独立应用两次线性变换加 ReLU，参数在不同层之间不同。

虽然线性变换在不同位置上是相同的，但它们在层与层之间使用不同的参数。另一种描述方式是将其视为两个核大小为 1 的卷积。输入和输出的维度为 d_model = 512，内层维度为 d_ff = 2048。

3.4 嵌入和 Softmax

与其他序列转换模型类似，我们使用学习到的嵌入将输入和输出令牌转换为维度为 d_model 的向量。我们还使用常规的学习线性变换和 softmax 函数将解码器输出转换为预测的下一个令牌概率。

在我们的模型中，我们在两个嵌入层和 softmax 之前的线性变换之间共享相同的权重矩阵。在嵌入层中，我们将这些权重乘以 √d_model。

嵌入权重共享：输入嵌入、输出嵌入与 softmax 前线性变换共用同一权重矩阵。乘以 √d_model 是为了让嵌入层与后续子层的尺度匹配。

3.5 位置编码

由于我们的模型不包含循环和卷积，为了让模型利用序列的顺序信息，我们必须注入关于序列中令牌相对或绝对位置的信息。为此，我们在编码器和解码器堆栈底部的输入嵌入中添加了"位置编码"。位置编码与嵌入具有相同的维度 d_model，以便两者可以相加。

在这项工作中，我们使用不同频率的正弦和余弦函数：

\[ PE_{(pos, 2i)} = \sin\left(pos / 10000^{2i/d_{\mathrm{model}}}\right) \] \[ PE_{(pos, 2i+1)} = \cos\left(pos / 10000^{2i/d_{\mathrm{model}}}\right) \]
正弦位置编码：第 pos 个位置的第 2i / 2i+1 维分别用正弦/余弦函数计算，波长形成几何级数。

其中 pos 是位置，i 是维度。也就是说，位置编码的每个维度对应一个正弦波。波长从 2π 到 10000·2π 形成几何级数。我们选择这个函数是因为我们假设它能让模型更容易地通过相对位置进行注意力学习，因为对于任何固定的偏移量 k，PE_{pos+k} 可以表示为 PE_{pos} 的线性函数。

我们还尝试了使用学习到的位置嵌入，并发现两种版本产生了几乎相同的结果（见表 3 第 (E) 行）。我们选择正弦波版本，是因为它可能允许模型外推到比训练时遇到的序列长度更长的序列。

🧭本节要点回顾
编码器与解码器的层结构有何异同？
都是 6 层，每层含多头自注意力 + 前馈；解码器额外多一个编码器-解码器注意力层，且自注意力带掩码。
缩放点积注意力中的"缩放"起什么作用？
防止 d_k 较大时点积过大导致 softmax 梯度消失；缩放因子为 1/√d_k。
为什么要用正弦位置编码而非可学习的位置嵌入？
两者效果几乎相同，但正弦版本可能让模型外推到更长的未见序列。
