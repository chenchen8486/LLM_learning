# 第 15 章 多模态扩展 · 分页规格

> 章定位：正文收官章。第 12–13 章解决「怎么推、怎么部署」，第 14 章解决「怎么用」，本章回答「模型能力的边界如何越出纯文本」——给 LLM 装上眼睛。
> 主线一句：模态鸿沟（像素 vs token）→ 视觉编码器（ViT 把图切块变向量）→ 模态对齐（CLIP 把图文压进同一空间 / 连接器把视觉特征翻译成 LLM 词嵌入）→ 训练流水线（分阶段放权）→ 统一架构（图像也 token 化，一切皆是 token）。
> 格式红线：第 12 章及以后章节不配定位条（2026-10-10 规范），每页全部图从图 1 起编号；不设动手验证区块；每页至少 1 张原创 SVG；minimind 无多模态实现，本章纯走论文路线。
> 骨干素材：ref_paper/2020_Transformers for Image Recognition at Scale（ViT 译文 + 44 图，15.2 专用）；其余四篇（CLIP/LLaVA/BLIP-2/Flamingo）与 Chameleon/VQ-VAE 均已于 2026-10-10 联网核实关键数字。

## ch15_2_vit.html 视觉编码器 ViT
- 标题建议：15.2 视觉编码器：ViT 把图像切成 Token
- h2 固定：15.2.1 从词到图块：patch embedding 就是视觉版的分词加嵌入（呼应第 2、3 章）；15.2.2 模型全貌：公式 (1)–(4) 逐项拆解（[CLS] token、可学习 1D 位置嵌入、Pre-LN Encoder、GELU MLP）；15.2.3 归纳偏置的取舍：CNN 先验 vs 数据规模（ImageNet 上输 BiT、JFT 上反超）；15.2.4 实验与内部表征：缩放研究（2–4 倍算力优势）与图 7 三联图解读；15.2.5 从 ViT 到 VLM：视觉编码器在多模态中的角色（为 15.3–15.4 铺垫）

## ch15_3_clip.html 模态对齐 I：CLIP
- 标题建议：15.3 模态对齐 I：CLIP 用对比学习打通图文
- h2 固定：15.3.1 监督信号的升级：从类别标签到 4 亿条自然语言描述；15.3.2 双塔架构与对称 InfoNCE 损失（公式拆解：N×N 相似度矩阵、对角线为正、可学习温度 τ）；15.3.3 zero-shot 分类：把类别名写成 prompt 的推理魔法（76.2% 匹敌全监督 ResNet-50，前 SOTA 仅 11.5%）；15.3.4 CLIP 的遗产：VLM 时代的事实标准视觉编码器（LLaVA/BLIP-2 都吃它的特征，呼应 15.4）
- 数字：WIT 400M 图文对；batch 32768；τ 初始化 0.07；ViT-L/14@336px 428M 参数；zero-shot ImageNet 76.2% top-1 / 95% top-5；ALIGN 1.8B 对 76.4%；分布偏移掉点 <10% vs 监督最高 40%
- 原创图：双塔 + N×N 相似度矩阵对比学习示意图（SVG，对角线高亮）；zero-shot 推理流程图

## ch15_4_connector.html 模态对齐 II：连接器
- 标题建议：15.4 模态对齐 II：连接器三世代——投影、查询与注入
- h2 固定：15.4.1 线性投影：LLaVA 的极简答案（单层 FC 把 CLIP 特征映射进词嵌入空间；原版 224px 下 16×16=256 视觉 token；LLaVA-1.5 升级双层 MLP + 336px→576 token）；15.4.2 可学习查询压缩：BLIP-2 的 Q-Former（32 个 768 维可学习查询，自注意力+隔块交叉注意力，257×1024 压成 32×768；188M 参数；ITC/ITM/ITG 三目标；zero-shot VQAv2 超 Flamingo-80B 8.7% 而可训练参数少 54 倍）；15.4.3 交叉注意力注入：Flamingo 的 Perceiver Resampler + GATED XATTN-DENSE（64 个 latent token；tanh 门零初始化，去门控掉 4.2 分；80B=70B Chinchilla+10B 新增层；per-image 掩码支持交错图文 few-shot）；15.4.4 横向对比：视觉 token 数 × 训练成本 × 表达能力（三代表格式对比与选型建议）
- 要点：连接器是全章枢纽——视觉编码器与 LLM 都冻结，只训这层翻译官；核心权衡是视觉 token 的数量与保真度
- 原创图：三世代连接器结构对比图（SVG）；Q-Former 查询挤压信息瓶颈图
- 论文：LLaVA 2304.08485（NeurIPS 2023 Oral）；BLIP-2 2301.12597（ICML 2023）；Flamingo 2204.14198（NeurIPS 2022）

## ch15_5_vlm_training.html VLM 训练流水线
- 标题建议：15.5 VLM 训练流水线：分阶段放权与数据配方
- h2 固定：15.5.1 训练总览：阶段化放权（对齐预训练只训连接器 → 指令微调放开 LLM；冻/放决策表对照 LLaVA/BLIP-2/Flamingo 三家）；15.5.2 数据配方：从图文对到视觉指令数据（595K 过滤 CC3M → 158K GPT-4 合成：58K 对话+23K 详述+77K 复杂推理；language-only GPT-4 + COCO 符号化标注的合成法）；15.5.3 失败模式与评测：对象幻觉与 POPE、综合基准 MME、ScienceQA 92.53%（GPT-4 协同）；15.5.4 现代配方演进：LLaVA-1.5 的启示（MLP 投影、高分辨率、学术任务数据混合）与「数据质量>数量」的共识

- 论文：LLaVA 2304.08485；LLaVA-1.5（2310.03744，Improved baselines）；POPE 2305.10355（EMNLP 2023）；MME 2306.13394

## ch15_6_unified.html 统一架构趋势
- 标题建议：15.6 统一架构趋势：一切皆是 Token
- h2 固定：15.6.1 拼接式 VLM 的天花板（模态鸿沟只是被桥接未被消除；视觉编码器成为能力与分辨率瓶颈）；15.6.2 图像的离散化：VQ-VAE 与图像分词器（encoder→codebook 最近邻→离散码→decoder；与第 2 章 BPE 对仗：BPE 从统计合并造词表，VQ 从重建学习造码本）；15.6.3 Chameleon：早期融合的统一建模（文本 BPE + 图像 8192 码本统一词表，混合序列自回归，7B/34B，交错图文生成）；15.6.4 代价与折中：统一范式的训练稳定性难题、图像生成路线一句话点到为止（扩散 vs 自回归）、GPT-4o/Gemini 原生多模态一句带过；15.6.5 全章收束：多模态在 LLM 生命周期中的位置（感知层的扩展，不改变第 0–14 章的任何机制）
