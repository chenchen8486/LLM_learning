# LLM 机制学习手册 — 开发方案

> 本文档是整个学习工程的设计基准与操作手册。任何章节 HTML 的开发、构建、风格规范均以本文件为准。
> 创建时间：2026-09-22

---

## 1. 工程目标

　　系统拆解大语言模型（LLM）从数据到部署的完整机制，沉淀为一套可离线浏览、带侧边栏导航、含 LaTeX 公式渲染与配图的中文学习手册。

- 学习对象：LLM 全生命周期知识，三大素材支柱：一手权威资料（原始论文、官方技术报告、经典教材）、`ref_paper/` 下 5 篇论文（Attention 论文是第 4 章骨干素材）、`minimind-master/` 可运行代码工程（机制描述的代码印证与动手验证素材）。
- 产出形态：沿用片段 → 构建脚本 → 套模板的构建体系，含公式渲染、配图自动复制、要点回顾卡片。
- 讲解标准：对标斯坦福等高校公开课水平。再高深的内容，也要讲得让非本专业读者听懂并感兴趣。深入浅出，先直觉类比再上公式，恰当例子贯穿始终。
- 防幻觉红线：所有讲解必须有一手资料依据，每个页面末尾列参考来源。严禁凭记忆编造公式、数据或实验结论。

## 2. 工作流程（核心约定）

　　本工程采用逐章迭代、先样板后批量的工作方式，不做一次性全量生成：

```
① 联网查证一手资料  →  ② 产出该章全部小节 HTML  →  ③ 用户浏览确认
        ↑                                              │
        │                                              ▼
   ⑥ 批量推进下一章  ←  ⑤ 沉淀/更新生成规范  ←  ④ 迭代打磨格式与内容
```

1. 查证资料：编写某章前，先用 WebSearch / FetchURL 收集该主题的一手资料（原始论文、官方文档、经典教材章节），整理事实清单。第 4 章改为通读 `ref_paper/2016_attention_is_all_you_need/*_zh.md` 原文。涉及模型实现机制的章节，写完后对照 `minimind-master/` 的对应代码自查一遍，防止讲得对但实现不是那样。
2. 整章产出：一次性产出该章所有小节片段，运行构建，让用户看到完整章节效果（导航、翻页、公式、配图、表格全要素）。
3. 用户确认：用户在浏览器中阅读，就视觉风格、内容深度、细节取舍给出反馈。
4. 迭代打磨：根据反馈调整，直至该章满意。第 2 章（分词）作为风格样板章，定稿后即冻结格式基线。
5. 沉淀规范：将定稿格式约定固化到 `docs/2_html编写规范.md`，作为后续章节的硬约束。
6. 批量推进：以样板章为模板，逐章推进其余章节，每章产出后仍走确认 → 打磨闭环。
7. 统一精修：全部章节完成后，用户通读推敲，一起做最后一轮内容与细节优化。

## 6. 构建体系说明

### 6.1 构建流程

1. 在 `output/html/pages/` 下新建片段，命名 `ch{章}_{节}_{短名}.html`（如 `ch2_1_bpe.html`）。
   - 每章的页面按节划分，一节一个文件，节序号从 1 开始连续编号。
   - 章号约定：0 到 16 对应正文各章，90 为附录。
2. 运行 `python output/html/build.py`，脚本自动完成：
   - 扫描所有片段，提取 `<h1>` 标题、正文、`<style>`、`<script>`。
   - 按文件名推导章节层级，生成侧边栏导航树、面包屑、上下节翻页。
   - 解析正文中形如 images/ch{章}/ 的图片引用，从 `ref_paper/*/images/` 自动复制同名图片到 `output/html/images/ch{章}/`。
   - 套用 `template.html` 与 `global.css`，输出成品 HTML。
3. 章节标题映射在 build.py 顶部 `CHAPTER_TITLES` 配置，新增章节时同步维护。

### 6.2 关键配置项（build.py 顶部）

| 配置 | 作用 |
|------|------|
| `CHAPTER_TITLES` | 章号 → 顶层导航/面包屑标题 |
| `NAV_GROUPS` | 三级小节的分组标题，当前命名规则下一般不用 |
| `REF_PAPER_DIR` | 配图源目录，默认 `../../ref_paper` |

### 6.3 配图引用约定

- 论文原图：图片名照抄 `ref_paper/<论文>/images/` 中的文件名，`src` 写 `images/ch{章}/<图片名>`，由 build.py 按图片名全局查找并复制。
- 原创示意图：用内联 SVG 手绘，规范见 `docs/2_html编写规范.md`。
